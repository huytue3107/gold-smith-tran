## Chạy Lệnh Khám Phá

```bash
Get-ChildItem -Force
Get-ChildItem -Recurse -File -Include *.md | Select-Object -First 30 FullName
```

Nếu đang ở shell Unix-compatible, có thể dùng:

```bash
ls -la
find . -type f -name "*.md" | head -30
```
